# お読みください

本スクリプトは、Adobe Illustrator上でJANバーコード（JAN-13 / JAN-8）をベクトルデータとして生成するツールです。

## 【特徴】

1. **無料**
   商用・非商用を問わず、改変・再配布・スクリプトへの組み込みなど、無料で自由にお使いいただけます。

2. **チェックディジット自動計算**
   12桁または7桁の入力だけで、チェックディジットを自動算出します。
   13桁または8桁で入力された場合は、チェックディジットを検証します。

3. **数字のアウトライン化オプション**
   実行時に数字の「アウトライン」化を選択可能。デフォルトの設定ではテキストを保持します。数字の描画を「なし」にすることもできます。

4. **ドキュメントのカラーモード自動判別**
   CMYKモードなら「K100%」、RGBモードなら「R0 G0 B0」を自動で選択して描画します。

5. **OCR Bフォント自動検索**
   OCR Bフォントがインストールされている場合は自動で適用します。
   *※ OCR B Std Regular フォントは、Adobe Fontsで利用できます。*

6. **グループ化されたデータ**
   生成されたバーコードは全体がグループ化されていますが、グループ解除を1回実行することで「バー」「数字」「背景」の3部に分かれます。
   バーコードの仕様上、バーの左右には適切な余白が必要ですが、「背景」はその余白を適切に確保するために付与しています。

7. **カスタム設定**
   コード内の「以下で設定のカスタムができます」で始まるブロックの値を編集することで、簡単に設定をカスタムすることもできます。
