# illustrator-jan-barcode
Illustrator用 JANバーコード生成スクリプト

## 概要
Adobe Illustrator用のJAN-13 / JAN-8バーコード生成スクリプトです。

## 使い方
1. Illustratorで `createJanBarcodeAi.jsx` を実行
2. JANコードを入力
3. サイズなどを指定してOK

## ヒント
OCR B Std Regular フォントは、Adobe Fontsで利用できます。
